## 👉 [開啟報告](https://timyangasus.github.io/KPI-/KPI_index.html)

https://timyangasus.github.io/KPI-/KPI_index.html

- [`KPI_index.html`](https://timyangasus.github.io/KPI-/KPI_index.html)：最新版報告，單一 HTML，截圖已內嵌，可離線開啟。

```bash
python3 _source/build.py _source/template_v2.html _source/img KPI_index.html
```
